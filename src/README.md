# Código-fonte (`src`)

Esta pasta contém os módulos principais do jogo.

## Arquivos

- `jogo.py`: loop principal.
- `estado.py`: trata do estado do jogo e suas atualizações.
- `tela.py`: renderização dos elementos do jogo.
- `item.py`: trata dos powers aleatórios gerados no jogo.
- `nave.py`: movimentação da nave do jogador.
- `meteoro.py`: criação e movimentação dos meteoros.
- `config.py`: constantes globais (tela, cores, caminhos, FPS).
- `funcoes.py`: funções auxiliares de regra e lógica.
- `dados.py`: leitura e gravação de dados (recorde/ranking).

## Dica de evolução

Quando o projeto crescer, mantenha módulos pequenos e separados por responsabilidade.
